[00 // EXECUTION_SPEC & PRIVACY]

Zero-mutation read pipeline.

  • Triggered strictly on manual invocation. Queries label IDs across INBOX threads, fetching full MIME payloads for up to 20 unlabelled conversations.
  • Scanning & Jev inference are strictly read-only. Gmail state is only mutated when you select rows and execute Apply selected labels.
  • Read phase uses gmail.readonly. Label mutation requests gmail.modify solely to create/attach Inbox Signal - * labels.
  • Threads already tagged with any Inbox Signal label are bypassed so older uncategorised packets can populate the 20-message window.
  • Header resolution runs locally; Jev only receives an enum token (to_me, cc_me, not_listed, unclear).
  • Subject, sender, plain-text excerpt (≤8KB), and sanitized link hostnames are relayed via 127.0.0.1:8787 to TypeSafe Jev.
